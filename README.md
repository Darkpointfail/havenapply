# Haven

The common application for senior living — one medical profile, many residences.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s included

- **Home** — brand hero, how it works, benefits, search preview, FAQ  
- **Residences** — Airbnb-style search, filters, premium cards  
- **Residence profile** — gallery, pricing, care team, reviews, apply CTA  
- **Application wizard** — multi-step, auto-save, review & confirmation  
- **Medical profile** — editable dashboard sections  
- **Applications** — Kanban status board  
- **Messages** — secure family ↔ residence chat  
- **Documents** — vault with categories, sharing, expiry  
- **For residences** — intake admin dashboard  

Built with Next.js, TypeScript, Tailwind CSS, and Framer Motion-ready UI patterns.
